## Estimated model routing

The **$393.29 routing component is entirely estimated**. It compares the frozen pre-tool model mix with current usage using fixed generation reference cards and token classes. It does not treat a change in a model's published price as a routing saving, and it does not establish that the optimizer caused every model choice. Unpriced token classes do not acquire a fallback family price. Routing is included once in the all-in subtotal.

## Population and exclusions

The snapshot covers **1,632 main work sessions and 3 delegated sessions**, 1,635 total. Action token counts can use text-length proxies. The provider-stats-compatible spent denominator is fresh input plus reported streamed assistant output from top-level sessions, without streaming deduplication. Request-deduplicated usage is a different metric.

Pricing uses recognized model and token-class cards. Premium modes or service modifiers absent from recorded usage are not reconstructed, so this is not a complete bill reconciliation. Sub-agent estimates depend on runtime telemetry; this Claude Code snapshot does not establish equivalent coverage on other platforms.

Shared read-time filters exclude test fixtures, media-only archive events and duplicate-install telemetry from counted views. Source ledger rows remain intact. Opportunity estimates, setup projections and whole-workload transformation estimates are not added to this action subtotal.

## Skeleton and quality methods

Large code files can be served as a recoverable skeleton only after a cohort meets its history gates: edit-within-five-turns below 15%, at least 20 reads and at least five sessions. A live tripwire demotes an active cohort when its edit rate exceeds 15%. Markdown stays measure-only by policy. The requested file is served in full; related-file skeletons use an archived original and fail open when archiving fails. Current cohort statistics are available from `measure.py cohorts status --json`; they are not included in this savings total.

Quality grades use the available platform signals. This snapshot supplies no grade histogram or updated historical skeleton-corpus valuation, so neither is shown as a current result. See [Read cache](/features/read-cache/) for the mechanism.
