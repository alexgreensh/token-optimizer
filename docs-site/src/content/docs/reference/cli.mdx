This page lists every command the Token Optimizer engine dispatches. The engine is a single Python script, `measure.py`, that ships inside the skill. All commands run through it.

## How to run a command

The full invocation form is:

```bash
cd ~/.claude/skills/token-optimizer/scripts && python3 measure.py <command> [args]
```

The `cd` form is convenient, not required: the engine resolves sibling modules relative to its own script directory. You can instead pass the full path to `measure.py`. On Windows, use `python` instead of `python3`.

Commands run for a non-default platform need the runtime prefix:

```bash
TOKEN_OPTIMIZER_RUNTIME=codex python3 measure.py report
```

`TOKEN_OPTIMIZER_RUNTIME` selects which platform adapter the engine targets (`claude`, `codex`, `opencode`, `copilot`, `hermes`, `cursor`, `antigravity`, `grok`). When unset, the engine defaults to Claude Code. `doctor` delegates to `codex-doctor` on Codex. On other non-Claude runtimes, Claude-targeting commands such as `report`, `quick`, and `doctor` can return a safe platform notice instead of performing the Claude audit. Use the explicit adapter doctor/summary verbs below; a runtime prefix does not make every command native.

Most read commands accept `--json` for machine-readable output. The flag is noted per command where the source confirms it.

## Global flags

These parse before command dispatch and apply to any command in the run.

| Flag | Effect | Default |
|---|---|---|
| `--context-size N` | Override the detected context window size for this run | Auto-detected |
| `--json` | Emit machine-readable JSON (where the command supports it) | Off (human output) |
| `--version`, `-v` | Print the installed version string and exit | n/a |

`--context-size` can also be set with the `TOKEN_OPTIMIZER_CONTEXT_SIZE` environment variable. See [Configuration](/reference/configuration/).

| Command | Description | Key flags |

## Devin

Set `TOKEN_OPTIMIZER_RUNTIME=devin` for shared measure commands.

| Command | Action |
|---|---|
| `devin-install [--auto \| --manual]` | Install explicit user skill and record local data consent; `--auto` also wires the automatic compression hooks, `--manual` removes them, neither keeps the active mode |
| `devin-uninstall [--purge]` | Remove unchanged owned files and Token Optimizer's own hook entries; optional --purge also deletes metrics, consent and stored captures, preserving edited or foreign files |
| `devin-doctor [--probe]` | Readiness, coexistence warnings and local filter probe; with automatic mode on, `--probe` proves the hook round trip |
| `devin-summary` | Numeric output estimates, no provider totals or cost |
| `devin-filter prepare` | Create new private stdout/stderr capture pair |
| `devin-filter seal --capture PATH --exit-code N` | Snapshot a caller-asserted completed capture |
| `devin-filter --stdout PATH --stderr PATH --exit-code N --session LABEL` | Filter sealed captures explicitly |
| `devin-filter recover --capture-id ID --exit-code N` | Revalidate and recover originals without compression |

The filter accepts fixed format hints: generic, git-status, git-log, listing, search, tests, build. Labels select shared compression patterns, never execute commands.
